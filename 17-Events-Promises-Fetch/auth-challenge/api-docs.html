User Auth API

v1.0

მომხმარებლის ავტორიზაციის API — რეგისტრაცია, ლოგინი, პროფილის მართვა. API-ს json-server ემულირებს ლოკალურად.

Base URL: http://localhost:3000

გაშვება

ტერმინალში გაუშვი auth-challenge ფოლდერიდან:

cd auth-challenge

npx json-server db.json

სერვერი ამუშავდება http://localhost:3000 მისამართზე.

POST /users ახალი მომხმარებლის რეგისტრაცია ▼
აღწერა

ქმნის ახალ მომხმარებელს ბაზაში. json-server ავტომატურად გენერირებს id-ს.

Content-Typeapplication/json

name *stringმომხმარებლის სახელი

{ "id": 3, "name": "ლუკა", "email": "luka@mail.com", "password": "mypass123", "city": "ქუთაისი" }

GET /users?email=...&password=... ლოგინი (მომხმარებლის ძიება) ▼
აღწერა

ეძებს მომხმარებელს ემაილითა და პაროლით. json-server ფილტრაციას query პარამეტრებით აკეთებს. თუ მომხმარებელი მოიძებნა, მასივში ერთი ელემენტი იქნება. თუ არ მოიძებნა — ცარიელი მასივი.

Query პარამეტრები
პარამეტრიტიპიაღწერა
email *stringმომხმარებლის ემაილი
password *stringმომხმარებლის პაროლი
Response (200 OK) — მომხმარებელი ნაპოვნია
[ { "id": 1, "name": "გიორგი", "email": "giorgi@mail.com", "password": "pass123", "city": "თბილისი" } ]
Response (200 OK) — არ მოიძებნა
[]

200 — OK

fetch მაგალითი

var email = "giorgi@mail.com"; var password = "pass123"; var response = await fetch( "http://localhost:3000/users?email=" + email + "&password=" + password ); var users = await response.json(); var user = users.length > 0 ? users[0] : null;
